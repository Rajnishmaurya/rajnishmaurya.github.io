This M.Tech project investigates open-source mathematical LLMs for generating mathematics questions with strong topic adherence, difficulty alignment, mathematical correctness, and structural consistency.

**Supervisor:** Prof. Nirav Bhatt, Department of Data Science and Artificial Intelligence, IIT Madras.

**Highlights**

- Evaluated 19 open-source mathematical LLMs using zero-shot and few-shot prompting.
- Built a curated 39K-sample fine-tuning dataset using DeepMath and OmniMath.
- Fine-tuned Qwen3-4B-Instruct using LoRA for parameter-efficient mathematical question generation.
- Improved difficulty alignment from 63.33% to 93.33% and usability from 53.33% to 90% after fine-tuning.
- Analyzed output diversity using Shannon entropy and uniqueness ratios.
