This MLOps course project focused on building a reproducible and deployable tweet sentiment classification pipeline.

**Highlights**

- Built sentiment classification using SVM with TF-IDF features.
- Containerized the inference API, monitoring stack, and MLflow tracking server using Docker Compose.
- Used FastAPI for serving predictions.
- Integrated DVC for reproducible data and model workflows.
- Added data drift detection via Prometheus PushGateway and visualized metrics in Grafana dashboards.
