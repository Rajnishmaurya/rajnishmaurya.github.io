## Research Interests

- Mathematical LLM evaluation and benchmarking
- Parameter-efficient fine-tuning using LoRA
- Question generation for mathematics education
- Vision-language and multimodal foundation models
- Reproducible machine learning and MLOps

## Current Project

My current M.Tech project is **Investigating LLMs for Mathematics Question Generation**, supervised by Prof. Nirav Bhatt at IIT Madras. The work evaluates open-source mathematical LLMs and fine-tunes Qwen3-4B-Instruct using LoRA for better mathematical question generation.
